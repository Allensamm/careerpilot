CareerPilot Hybrid v0.6

Encrypted on your device. Local vault by default. Optional consented cloud package for offline automation.

Encrypted vault
Security: AES-256-GCM encryption in browser IndexedDB, using a passphrase-derived key. The passphrase is not stored. If forgotten, the vault cannot be recovered. Data is decrypted in memory while unlocked. No real applications are submitted in this prototype. Public job feeds may see your IP address.

Run python agent/local_agent.py on this computer. It accepts public job IDs only, never CVs or profiles. No submissions are performed.

5. Optional 24/7 cloud package (prototype)

Explicit opt-in. Sends your name, email, target role, region, and detected skills to the cloud service, where they are encrypted at rest for up to 24 hours. This does NOT upload your full CV, run applications, or guarantee zero server exposure. The cloud service can decrypt this package. Do not use real personal data for testing.
